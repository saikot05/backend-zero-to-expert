## 📖 About

**English:** A step-by-step learning path to become a professional backend developer. Every module has theory, code examples, practice tasks, interview questions and links to the best free resources.

**বাংলা:** Professional backend developer হওয়ার জন্য ধাপে ধাপে শেখার path। প্রতিটা module এ theory, code example, practice task, interview question আর সেরা free resource এর link আছে।

3. Finish the practice tasks
4. Revise the interview questions at the end of each module
